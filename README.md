# GlobalBridge 跨境电商全链路模拟

按《跨境电商全链路模拟系统》V1.3 做的教学模拟。它把选品、采购供应商风险、批量上架、广告、经营看板、学习中心、术语词典、中英界面、浅色/深色和管理员参数放在同一条可计算的链路里。

数字不是截图里的固定样例。毛利率、真实利润、订单、ACoS 和成本环都由同一套规则现算。课程 2.2 的公式是：

真实利润 = 销售额 − 采购成本 − 运营费用 − 物流与 fulfillment 费用 − 退货/纠纷成本 − 资金成本 − 机会成本

销售额按已扣除平台佣金的到手收入计算。选品卡片上的利润率是毛利率，用来排序；详情里的瀑布才是真实利润。

## 怎么用

学员在注册页用邮箱注册。管理员不能自行注册，只能由超级管理员在管理控制台添加。超级管理员、管理员和学员登录后看到的界面不同。

1. 学员打开注册页，填写称呼、邮箱和密码。
2. 超级管理员用分配的账号登录后，在「管理员账号」里添加管理员。管理员再用该账号登录，进入深色的管理控制台。
3. 学习中心打开「2.2 真实利润核算公式」。
4. 在选品模拟里筛选，打开商品看瀑布，把通过的商品放进清单。
5. 在采购页对比三家供应商。风险分 60 以上必须确认。清单里的折叠砧板还没有库存，适合走完采购、入库和上架。交期最短的供应商两天到货。
6. 推进模拟日，直到采购单入库。
7. 批量上架。没有库存只能存草稿；高合规风险的到货发布后会被抑制。
8. 给在售链接建广告，再推进几天。
9. 在看板核对销售额、成本环和流水，并下载 CSV。

演示店自带期初库存和 18 条广告，方便先看运营页和看板。你自己的商品仍然要从清单走完。

语言在顶栏切换。主题可选浅色、深色或跟随系统。管理员登录后可以修改佣金、退货率、广告占比和供应商风险权重。学员账号看不到这些参数。

账号存在应用数据库里。每个账号的进度、采购和帖子存在这台浏览器，互不影响。清除站点数据会回到该账号的演示店期初，账号本身还在。

## 本地运行

```bash
npm install
npm run dev
```

开发服务默认在端口 3847。
